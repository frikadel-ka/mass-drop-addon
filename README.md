# ⚖️ Mass Drop Addon for Blender

[![Blender 4.3+](https://img.shields.io/badge/Blender-4.3%2B-orange.svg)](https://www.blender.org/)
[![License: GPL v3](https://img.shields.io/badge/License-GPLv3-blue.svg)](https://www.gnu.org/licenses/gpl-3.0)

Аддон для расчёта центра масс объектов и визуализации его проекции в реальном времени. Позволяет собрать произвольный набор объектов, задать каждому массу или плотность и получить точный общий центр масс сцен — с живой линией проекции на плоскость XY.

![Preview](docs/preview.gif) <!-- Добавьте сюда GIF или скриншот работы аддона -->

---

## ✨ Основные возможности

* **Динамический список объектов:** Добавление выделенных объектов в список, удаление, автоматическая очистка при удалении из сцены.
* **Масса или плотность:** Для каждого объекта можно задать массу напрямую либо указать плотность материала — объём считается по геометрии с учётом модификаторов.
* **Точный расчёт COM:** Для замкнутых мешей используется объёмный центр масс (через разбиение на тетраэдры), для открытых — центроид по площади граней.
* **Живая проекция:** Линия от центра масс до плоскости XY рисуется через GPU в реальном времени и обновляется при движении объектов.
* **Кэширование с инвалидацией:** Локальный COM кэшируется и пересчитывается только при реальном изменении геометрии — быстро даже на тяжёлых сценах.
* **Перемещение 3D-курсора:** Кнопка мгновенно ставит 3D-курсор в вычисленный центр масс.
* **Несколько сцен:** Панель работает в любом 3D-вьюпорте, проекция корректно следует за активной сценой.

## 📥 Установка

1. Скачайте архив `mass_drop-vX.X.X.zip` со страницы **[Releases](../../releases)** (НЕ используйте кнопку *Code -> Download ZIP*).
2. Откройте Blender и перейдите в **Edit > Preferences > Add-ons**.
3. Нажмите кнопку **Install...** (или **Install from Disk** в Blender 4.2+) в правом верхнем углу.
4. Выберите скачанный `.zip` архив и установите галочку напротив **Mass Drop**.

---

## 🚀 Быстрый старт

1. Откройте **3D Viewport** и нажмите клавишу `N`, чтобы открыть боковую панель.
2. Перейдите во вкладку **Mass Drop Tools**.
3. Выделите объекты и нажмите **Import Selected Objects** — они появятся в списке.
4. Для каждого объекта выберите режим ввода: **Mass** (масса напрямую) или **Density** (плотность × объём).
5. Включите **Live Projection**, чтобы увидеть линию от центра масс до плоскости XY.
6. Нажмите **Calculate Center of Mass** — 3D-курсор переместится в точку COM.

## ⚙️ Работа со списком объектов

| Элемент | Описание |
| :--- | :--- |
| **Import Selected Objects** | Полностью заменяет список выделенными объектами сцены |
| **Add Objects** | Добавляет выделенные объекты к текущему списку, дубликаты пропускаются с предупреждением |
| **Remove Object** | Удаляет выделенный в списке элемент |
| **Mode: Mass / Density** | Переключатель режима ввода для каждого объекта независимо |
| **Mass** | Прямое значение массы (кг) |
| **Density (ρ)** | Плотность материала; масса считается как `объём × плотность` |

> Элементы, чьи объекты были удалены из сцены, автоматически исчезают из списка — вручную чистить ничего не нужно.

## 🧮 Как считается центр масс

1. Для каждого объекта вычисляется **локальный COM** в его собственных координатах:
   * для замкнутой геометрии — через ориентированный объём тетраэдров (точный объёмный центр);
   * для открытой геометрии — центроид, взвешенный по площади граней.
2. Локальный COM умножается на `matrix_world` — получается глобальная точка.
3. Общий COM сцены — средневзвешенное по массам всех объектов списка:

   ```
   COM = Σ (масса_i × точка_i) / Σ масса_i
   ```

Локальный COM кэшируется и пересчитывается только при изменении геометрии объекта (правка вершин, модификаторы, подмена меша). Сдвиг, поворот и масштаб кэш не сбрасывают — `matrix_world` читается заново на каждом кадре.

| Параметр | Описание |
| :--- | :--- |
| **Live Projection** | Включает/выключает линию от COM до плоскости XY в реальном времени |
| **Material Density** | Плотность по умолчанию для режима Density |

## ⚠️ Известные ограничения

* **Только `Mesh`.** Empty, Camera, Light, Curve, Text, Metaball и т.п. игнорируются — вклад в COM они не дают.
* **Один материал на объект.** Разные плотности для разных частей одного меша не поддерживаются.
* **Незамкнутая геометрия.** Для открытых мешей COM считается по поверхности, а не по объёму — «центр поверхности», а не центр массы.
* **Самопересечения и вывернутые нормали.** Замкнутый меш с такими дефектами даёт некорректный COM. Перед расчётом: `Shift+N` (Recalculate Outside).
* **Неравномерный масштаб в режиме Density.** Объём умножается на `scale.x·scale.y·scale.z` — для неравномерного масштаба это приближение.
* **Один поток.** Первый расчёт тяжёлого меша подвисает интерфейс, дальше работает кэш.
* **Настройки на сцене.** В файле с несколькими сценами у каждой свой список и своя проекция.
* **Геометрический COM, а не физический.** Полости и неоднородная плотность внутри меша не учитываются — для сложных случаев задавайте массу вручную.

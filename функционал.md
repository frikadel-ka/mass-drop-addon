Что должен делать аддон:
рисовать точку в центре масс, вектор силы тяжести к установленному объекту, проекция вектора на этот объект.

Как это сделать?:
1. выбираешь объекты
2. устанавливаешь материал, плотность или массу для каждого объекта
3. выбираешь объект "притяжения" куда будет стремиться вектор силы тяжести
4. выбираешь объект на котором будет проецироваться вектор

Важные примечания: возможность выбирать объекты через выделение -> "кнопка применения" после чего они появляются в списке объекта, в котором тоже можно убирать и добавлять объекты и также изменять параметры материала, плотности или веса (только пока хз как). центр масс для каждого объекта расчитывается по опр. функции. вектор силы притяжения кроме как к ориджину объекта, можно брать из готового вектора - меша который создал сам пользователь, математически, где он сам вводит направление или по осям координат (надо придумать как лучше или сделать все). ну и в конце просто выбрать объект или объекты куда будет проецироваться вектор. также настройки точки, вектора и проекции должны быть гибкими

То что нужно для MVP:
объекты через выделение и список, массы для каждого объекта, вектор или объект силы тяжести(снчала сделать объект), объект для проекции. Из UI только: словарь объект:масса, объект силы, объект проекции. В MVP уже все должно обновляться при изменении (если сложно сначала сделать кнопку которая будет обновлять но лучше без лишней работы сразу норм)

Род-мап создания: 1. Property сначала для словаря, 2. Operator с функцией где центр масс лежит в ориджине но сделать функцию расширяемой, 3. UI со словарем и кнопкой создания пустышки, 4. Operator и UI для кнопок и функций вектора к объекту и проекции этого вектора на объект, 5. Отладка + Прочее.
